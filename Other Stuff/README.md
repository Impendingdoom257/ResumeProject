VCS254ResumeSite

Resume site for CS254

Landing Page

Must include an “About Me” section, skills summary, and relevant contact details.

Minimum required sections:

    Heading with your name or personal branding

    About/Introduction (brief bio)

    Skills/Experience (list your technical or non-technical skills)

    Contact Information (email, GitHub link, LinkedIn, or any other professional/social links)

The page should have clean, readable formatting. Students may use any styling they wish (pure CSS or a simple framework), but must be able to demonstrate proficiency in HTML/CSS basics.

Version Control

Students should maintain their landing page files in a Git repository (GitHub, GitLab, etc.).

Commit messages should be descriptive, indicating changes or updates made.

Cloudflare Pages Deployment

Students must create a Cloudflare Pages project linked to their repository.

Ensure continuous deployment is enabled so that new changes automatically trigger a redeploy.

Custom Domain Setup - Optional

Students could configure a custom domain. (e.g., yourname.com or a subdomain of your personal domain, resume.yourname.com)

Validate that the site is accessible at the custom domain via secure HTTPS.

Optional Enhancements (Not required but encouraged for extra practice)

Adding a simple contact form that uses a third-party service (like Formspree).

Including a short portfolio section with images or links to past projects.

Incorporating responsive design (ensuring the layout looks good on mobile devices).
